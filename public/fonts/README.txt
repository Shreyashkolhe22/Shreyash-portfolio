Drop the Anurati font file here.

    Anurati-Regular.woff2     (preferred - smallest)
    Anurati-Regular.otf       (works too)
    Anurati-Regular.ttf       (works too)

Any ONE of these is enough. Anurati is not on Google Fonts and cannot be
loaded from a CDN, so it has to be self-hosted. It is free for personal use
(designer: Emmeran Richard) - download it from the designer's own page.

Nothing else needs changing: the desktop clock detects the font on reload and
switches to Anurati's wider tracking by itself. Until then it renders with a
thin geometric fallback.
